# AIOS Internationalization (i18n)

AIOS uses GNU `gettext` (`gettext` / `eval_gettext`) for CLI localization. Source scripts use Simplified Chinese (`zh_CN`) as the canonical `msgid`, while `i18n/aios.sh.pot` provides an English reference template so non-Chinese speakers can translate from English into any language.

## Directory Layout

| Path | Tracked in Git | Purpose |
| :--- | :---: | :--- |
| `make-pot.sh` | Yes | Extracts strings, merges `.po` catalogs, remaps English `msgid` back to `zh_CN`, strips obsolete entries, and compiles `.mo` binaries |
| `aios.sh.pot` | Yes | English base template (`msgid` in English, empty `msgstr`) for proofreading English and translating into other languages |
| `po/aios.sh-<lang>.po` | Yes (except `en`) | Human-editable translation catalog for `<lang>` |
| `po/aios.sh-<lang>.mo` | Yes | Compiled binary catalog loaded by `gettext` at runtime |
| `aios.sh-en.pot`, `aios.sh-zh_CN.pot` | Ignored | Intermediate templates generated by `make-pot.sh` |

## Prerequisites

- GNU `gettext` (`xgettext`, `msgmerge`, `msgfmt`, `msgattrib`, `msguniq`, `msgunfmt`)
- GNU `gawk` and GNU `sed` (`gsed` on macOS)

`make-pot.sh` will automatically install missing dependencies via Homebrew (macOS) or `apt`/`yum` (Linux).

## Translating into a New or Existing Language

Clone the repository and enter `i18n/` (or invoke `./i18n/make-pot.sh` from the repository root):

```bash
git clone https://github.com/woniuzfb/aios.git
cd aios/i18n
```

### Option A: Translate from English (recommended for non-Chinese speakers)

```bash
# 1. Generate/update po/aios.sh-<lang>.po with English msgids (e.g. ru, de, ja)
./make-pot.sh en ru

# 2. Translate po/aios.sh-ru.po with Poedit or any text editor
poedit po/aios.sh-ru.po

# 3. Remap English msgids back to zh_CN (by dictionary lookup) and compile po/aios.sh-ru.mo
./make-pot.sh zh_CN ru
```

### Option B: Translate directly from Simplified Chinese

```bash
# 1. Generate/update po/aios.sh-<lang>.po with zh_CN msgids
./make-pot.sh zh_CN ru

# 2. Translate po/aios.sh-ru.po
poedit po/aios.sh-ru.po

# 3. Clean obsolete entries and compile po/aios.sh-ru.mo
./make-pot.sh zh_CN ru
```

### Translation Guidelines

- **Keep all Shell variables intact**: Never translate, rename, remove, or add variables such as `$info`, `$error`, `$tip`, `${green}`, `${red}`, `${normal}`, or `$var`.
- **Keep escape sequences valid**: Escape inner double quotes as `\"` and represent newlines as `\n` (do not insert raw line breaks inside a single-line `msgstr`).
- **Verify before opening a PR**:

  ```bash
  msgfmt --check --statistics -o /dev/null po/aios.sh-<lang>.po
  ```

Open a Pull Request with `i18n/po/aios.sh-<lang>.po` (and `i18n/po/aios.sh-<lang>.mo`).

## Proofreading English (`aios.sh.pot`)

If you are a native English speaker and want to refine the English wording:

1. Edit `i18n/aios.sh.pot` (update `msgid` strings while keeping all Shell variables intact), or run `./make-pot.sh zh_CN en` first to restore `po/aios.sh-en.po` from `po/aios.sh-en.mo` and edit it directly.
2. Validate syntax with `msgfmt --check -o /dev/null i18n/aios.sh.pot`.
3. Open a Pull Request with `i18n/aios.sh.pot`.

## Maintainer Workflow (After Changing Source Strings)

When adding, modifying, or removing translatable CLI strings in `utils/*` or `src/*`:

1. Follow the coding rules:
   - Static Chinese strings: `$(gettext "中文文案")` (place trailing `:` / `...` / `\n` outside when possible to maximize reuse).
   - Strings with simple variables: `$(eval_gettext "\$info 文案 \$var")` (escape variables with `\$`, keep trailing `\n` outside, do not use `$"..."`).
   - Complex Bash expansions (`${arr[i]}`, `${var:-default}`, `$((...))`, `$1`) are not supported by `envsubst`; assign to a simple local variable first or concatenate `$(gettext "...")` segments.
   - Labels inside `jq` filters: pass via `--arg` (few strings) or a cached `--argjson i18n` dictionary built with `$ARGS.named`.
2. Rebuild, sync `docs/aios.sh`, and refresh `.pot` / `.po` / `.mo`:

   ```bash
   ./make && bash -n aios.sh
   cp aios.sh docs/aios.sh && chmod +x docs/aios.sh

   # Restore po/aios.sh-en.po from .mo if missing, refresh zh_CN template, merge, and strip obsolete entries
   ./i18n/make-pot.sh zh_CN en

   # Fill in any new untranslated English strings in i18n/po/aios.sh-en.po, then verify & compile
   msgfmt --check --statistics -o i18n/po/aios.sh-en.mo i18n/po/aios.sh-en.po

   # Export deduplicated English base template i18n/aios.sh.pot and verify
   ./i18n/make-pot.sh b
   msgfmt --check --statistics -o /dev/null i18n/aios.sh.pot
   ```
